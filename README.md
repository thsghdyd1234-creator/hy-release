# hy-release

연구실용 hy 툴 배포 저장소입니다. AutoCAD 리습, SketchUp 루비, Photoshop·Illustrator·InDesign 플러그인과 프로그램을 여기서 받습니다.

## 설치하는 법

**hy 허브** 프로그램으로 설치하고 업데이트합니다. 허브는 준비 중입니다.

허브가 하는 일:
- 툴 목록과 설명을 보여 줍니다.
- 툴마다 종류에 맞는 위치에 설치합니다. 리습 자동 로드, 스케치업 플러그인, Adobe 플러그인을 다 처리합니다.
- 새 버전이 나오면 알려 주고, 변경 내역을 보여 준 뒤 버튼을 누르면 업데이트합니다.
- 업데이트 후 문제가 있으면 이전 버전으로 되돌립니다.
- 업데이트해도 프리셋과 설정 같은 사용자 데이터는 지우지 않습니다.

## 이 저장소에 있는 것

| 위치 | 내용 |
|---|---|
| `catalog.json` | 허브가 읽는 툴 목록·버전·변경 내역 |
| Releases | 툴별 설치 파일. 태그는 `<툴 id>-v<버전>` |

이름에 "pre-release"가 붙은 릴리스는 테스트 중인 버전입니다.
